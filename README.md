An invented passport spread for the Republic of Solmara — a country that
doesn't exist. `main.py` (pure Python 3.13 standard library, no network)
draws one open passport spread and writes it to `/output/entry.png`: a data
page with a portrait, personal details and a machine-readable zone, and a
visa page with arrival and departure stamps from the neighbouring countries
of Kavarra, Telmor and the Isle of Narin, plus the visa condition that gives
the place away — entry to the Coral Free Zone is by sea ferry only, the
bearer travels on a fishing licence, not a work permit.

Every date agrees: the passport was issued 12 JAN 2021 in Port Lumen and
expires 12 JAN 2031, and every stamp falls between the two.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
